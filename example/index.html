FastComments · Jekyll

Comments for Jekyll, in one Liquid tag.

Every FastComments widget as a Jekyll Liquid tag. Set your tenant id once in _config.yml, then drop {% raw %}{% fastcomments %}{% endraw %} into any layout, post, or page. This showcase runs against the public demo tenant.
